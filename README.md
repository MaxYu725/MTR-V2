# 🚆 MTR Metro Ultra 2.0 (港鐵領航 Pro)

基於 `MTRMetroApp` 全面重構與華麗升級的次世代香港港鐵 Android 應用程式。採用 **Cyber-Transit & Neo-Glassmorphism（流光毛玻璃擬態）** 設計語言，結合離線全網車資資料庫、三模式智慧路徑規劃引擎、實時抵站倒數、車站全方位百科與天文台天氣預警中心。

---

## ✨ 2.0 核心升級亮點

1. **🎨 次世代流光毛玻璃介面 (Cyber-Glass UI & 雙主題切換)**
   - 支援 **深色流光模式 (Obsidian Dark)** 與 **清晰日照模式 (Daylight Mode)** 一鍵切換，地圖底圖亦會隨主題自動同步。
   - 保留經典 **Metro Pivot 滑動標題** 並新增 **懸浮毛玻璃底部導航列 (Floating Glass Dock)**，單手操作更流暢。

2. **🏠 智慧通勤看板 (`Home`)**
   - **永久保存設定 (`localStorage`)**：解決舊版重啟後釘選班次消失的問題，完整保存個人釘選車站與收藏路線。
   - **釘選班次磚 2.0**：新增視覺化倒數進度條、月台編號標籤、一鍵 **「⇅ 切換上/下行方向」** 及一鍵設為路線起點。
   - **📍 智能定位最近車站**：透過 GPS 經緯度計算身邊最近的港鐵站與直線距離，一鍵查看班次或設為起點。
   - **⭐ 常用通勤路線卡片**：在首頁直接顯示收藏的「起點 ➔ 終點」行程時間與八達通車資，點擊瞬間啟動導航。

3. **🧭 車站全方位百科 (`Explorer`)**
   - **即時模糊搜尋 + 路綫篩選膠囊**：支援輸入中英文站名或 3 字母代碼（如 `CEN`, `MOK`, `尖沙咀`）秒速過濾。
   - **三合一車站資訊抽屜**：
     - **⏱️ 即時班次**：支援跨綫轉乘站（如金鐘、旺角、大圍）自由切換不同路綫月台之實時到站時間。
     - **🚪 出口與設施**：內建全網 98 個車站主要出口地標（A/B/C/D...）、站內洗手間、育嬰室、無障礙升降機及轉乘月台構造提示。
     - **🚆 首末班車 & 車資速查**：顯示該站頭班車與尾班車開出時間，以及前往全港核心大站的八達通/單程票車資一覽。

4. **🗺️ 多維度智慧路線規劃與動態流光地圖 (`Planner`)**
   - **雙向選站體驗**：除了直接點擊互動地圖，新增 **「列表選站 ▾」快速搜尋視窗**，不必再於地圖慢慢放大尋找小圓點。
   - **三種路徑演算法模式**：
     - `⚡ 最快時間`：結合實時行車時間與平均轉乘步程。
     - `🔄 最少轉乘`：優先推薦直達或最少換綫方案（適合攜帶大型行李或雨天）。
     - `🛋️ 對面月台優先`：優先導引經過旺角、太子、金鐘、北角、調景嶺、荔景等同層對面月台轉乘站。
   - **全票種離線車資計算機**：內建 8,836 組車站對車資矩陣 (`mtr_fares.json`)，一鍵切換 **成人八達通**、**單程車票**、**小童/學生特惠** 及 **樂悠咭/長者 $2 優惠**。
   - **最佳轉乘車廂與步程指引**：每段轉乘均提供月台構造與建議上車車廂位置（如「同層對面月台直達轉乘，建議乘搭第 4-6 卡」）。

5. **⚡ 全網車務與天文台天氣預警中心 (`Status`)**
   - 串接 **香港天文台 (HKO) 開放數據**，即時顯示氣溫與熱帶氣旋／暴雨警告。
   - 內建 **「🧪 模擬事故演練」** 模式，可隨時預覽八號風球或信號故障時的突發警報介面，並提供全網 10 條港鐵路綫的 **突發替代巴士／渡輪應變指南**。

## ☁️ 如何在雲端一鍵打包 Android APK

### 方法 A：透過 GitHub Actions 自動雲端打包（最推薦，免安裝任何環境）
1. 將本專案檔案上傳（Push）至你的 GitHub Repository (`MTR_Metro_App`)。
2. 點擊 GitHub 頂部的 **Actions** 分頁，工作流 `Build MTR Metro Ultra Android APK` 會自動啟動（亦可手動點擊 `Run workflow`）。
3. 約 2 分鐘編譯完成後，點入該次執行紀錄底部的 **Artifacts** 區塊，下載 `MTR_Metro_Ultra_v2_APK` 即可獲得 `app-debug.apk` 安裝至手機！
   > 💡 **離線極速載入優化**：新版 `capacitor.config.json` 已將所有網頁與 `mtr_fares.json` 直接封裝進 APK 內部 (`webDir: "src"`)，即使在地底隧道無網絡訊號時，路線規劃、出口查詢與車資計算依然能 **0 毫秒離線秒開**！

### 方法 B：在 GitHub Codespaces 或 Google Project IDX 雲端終端機打包
```bash
npm install
npx cap add android
cp -rf custom_icons/* android/app/src/main/res/
npx cap sync android
cd android && ./gradlew assembleDebug
```
編譯完成的 APK 位於 `android/app/build/outputs/apk/debug/app-debug.apk`。
